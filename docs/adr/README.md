# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the
Stellar Bounty Board project. Each ADR documents a significant architectural
choice, the alternatives considered, and the rationale for the decision.

## Maintenance

To add a new ADR, create a file named `NNNN-title-slug.md` following the
template used by existing records, then update this index.
