# Release Process

Maintainer-only checklist for cutting a new release of stellar-bounty-board.

## Pre-Release

1. Confirm `main` is green:
   ```bash
   gh run list --branch main --limit 5
   ```
   Every recent CI run should be `success`.
2. Confirm the test suite passes locally:
   ```bash
   cd backend && npm test
   cd ../frontend && npm test
   ```
3. Regenerate OpenAPI to capture any route changes:
   ```bash
   cd backend && npm run gen:openapi
   git diff docs/openapi.generated.json   # review for unexpected changes
   ```
4. Update CHANGELOG (if one exists) with all merged PRs since the last release:
   ```bash
   gh pr list --state merged --base main --limit 50
   ```

## Version Bump

We follow semver:

| Change type | Bump |
| ----------- | ---- |
| Breaking API or contract change | major |
| New feature, backwards compatible | minor |
| Bug fix, docs, refactors | patch |

Update `package.json` version in both `backend/package.json` and `frontend/package.json`.

## Tag

```bash
git tag -s v1.2.3 -m "Release v1.2.3"
git push origin v1.2.3
```

## GitHub Release

Use `gh release create`:

```bash
gh release create v1.2.3 \
  --title "v1.2.3 — <short summary>" \
  --notes-file <(cat <<EOF
## Highlights

- <one-line summary of biggest change>

## Merged PRs

$(gh pr list --state merged --base main --limit 50 --json number,title,author | jq -r '.[] | "- #\(.number) \(.title) — @\(.author.login)")')

## Contributors

<auto-generated by `gh` or github-release-notes>
EOF
)
```

## Post-Release

1. Verify the GitHub Release page renders correctly.
2. Trigger the `docker-publish.yml` workflow manually (it watches tags but a manual trigger confirms the image built).
3. Post a link to the release in the project's chat channel.
4. Bump the dependency in any consumer repo that pins to this one (none currently).

## Rollback

If the release introduces a regression:

1. Mark the release as a pre-release on GitHub.
2. Revert the merge commits via `git revert <sha>` into `main`.
3. Cut a patch release following the same process above.
